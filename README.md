# Cotyrie

Un outil indépendant pour Guild Wars 2 qui lit la progression réelle de chaque joueur, la croise au sein d'un groupe et propose quoi faire ensemble, avec la raison de chaque suggestion.

*Cotyrie* est un nom provisoire.
